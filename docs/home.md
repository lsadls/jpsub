# 主页使用说明

双击/运行不带参数的命令，会自动打开浏览器主页（也可以用 `jpsub home`）。

![主页](home.png)

页面分四部分，**所有操作都在页面上点按钮完成，不用敲命令**：

- **① 操作**：输入 **sm 号或视频网址**点「下载并翻译」，或点「选视频…」选**本地视频**后点「翻译(run)」。按钮按用途分成行内标签组：**输入**（下载与本地视频的全部入口）、**编辑与翻译**（编辑 / 打码 / 选择原视频字幕区域 / 续翻 / 重翻 / AI 校对 / 翻译用量 / AI 接口预设 / 术语表）、**产出与分享**（生成字幕 / 烧录 / 投稿 / 复制info / 复制tag）、**删除(不可恢复)**（删除工作目录 / 删除视频，单独用红框隔开，避免误点）；输入/编辑与翻译/产出与分享组作用于 ② 中选中的条目。按钮永不置灰，无效操作会弹提示。下方「**Debug 日志**」复选框勾选后，本页所有按钮发起的任务都自动追加 `--debug`，把抽帧/筛选/OCR/合并等全流程写入 `logs/debug.log`（`-s` 批量脚本不受影响，详见 [cli.md](cli.md) 第 17 节）；
- **② output 列表**：自动列出 output/ 里的视频和 `.jpsub` 工作目录，每 3 秒自动刷新，显示「已生成字幕」「N 条未译」等徽章，**点击行选中**；
- **③ 批量脚本**：多行脚本框（每行一条任务，等价 `jpsub -s`，见 [batch.md](batch.md)），点「运行脚本」批量执行，输出实时显示在下方框里；
- **④ 任务**：所有后台任务的实时进度（下载/OCR/翻译百分比、已完成/失败），每 1 秒刷新，每条标识为「视频名+操作」，**点击选中后可点「终止选中」结束它**。

## 常用操作

| 想做什么                                 | 怎么做                                                                 |
| ---------------------------------------- | ---------------------------------------------------------------------- |
| 下载 niconico 视频并生成中文字幕         | ① 输入 sm 号/网址 → 「下载并翻译」                                     |
| 下载但先不翻译（之后用「编辑」改译文）   | ① 输入 sm 号/网址 → 「下载不翻译」                                     |
| 下载并把字幕直接烧进视频                 | ① 输入 sm 号/网址 → 「下载+烧录」                                      |
| 本地视频生成中文字幕                     | ① 输入本地视频路径 → 「翻译(run)」                                     |
| 本地视频字幕烧进视频                     | ① 输入路径 → 「翻译+烧录」                                             |
| 只生成日文原文和时间轴（不调 AI）        | ① 输入路径 → 「仅抽帧OCR」                                             |
| 改译文 / 删字幕 / 加字幕                 | ② 选中条目 → 「编辑」（见 [edit.md](edit.md)）                         |
| 给画面打码                               | ② 选中条目 → 「打码」（见 [mask.md](mask.md)）                         |
| 用改好的译文重新生成字幕文件             | ② 选中条目 → 「生成字幕」                                              |
| 继续翻译没翻完的句子                     | ② 选中条目 → 「续翻」                                                  |
| 推倒重来：重新 OCR / 重新翻译            | 「重新OCR翻译」「重新OCR」按钮或 ② 选中条目 → 「重翻」（等价 --force） |
| 把已有字幕烧进视频（打过码则先打码再烧） | ② 选中条目 → 「烧录」                                                  |
| 投稿到 B 站（biliup）                    | ② 选中条目 → 「投稿」，弹窗确认标题/简介/标签/分区/定时发布（见 [upload.md](upload.md)） |
| 框选原字幕位置（生成 --crop 参数）       | ② 选中条目 → 「选择原视频字幕区域」，拖框保存，抽帧时自动优先使用      |
| 查看视频信息 / 复制标签                  | ② 选中条目 → 「复制info」（复制 info.txt）/「复制tag」（点选单个标签） |
| 删除工作目录 / 删除视频                  | ② 选中条目 → 「删除工作目录」（字幕译文全删、视频保留）/「删除视频」   |
| 导入现成字幕文件/整理格式                | ①「字幕文件」区填路径选操作（导入工作目录 / 合并碎片 / 排版 / 格式转换）→ 执行（见 [cli.md](cli.md) 第 18 节） |
| 查看/编辑名词对照表                      | 「编辑与翻译」组 →「术语表」弹窗，切换全局/当前工作目录，保存即写盘；「识别角色名」从选中条目的原文自动追加候选（见 [cli.md](cli.md) 第 13 节） |
| 直接跑一条 jpsub 命令                    | ① 「自定义命令」框输入完整命令（如 `download sm123 -v 720p`）→ 运行    |
| 排查时间轴/OCR 异常（留调试日志）        | ① 勾选「Debug 日志」→ 点按钮跑任务 → 查看 `logs/debug.log`             |
| 打开 output 文件夹                       | ② 标题旁「打开文件夹」                                                 |
| 一次处理很多视频                         | ③ 脚本框每行写一个 sm 号 → 「运行脚本」（见 [batch.md](batch.md)）     |
| 退出程序（含运行中的任务）               | 右上角「退出程序」                                                     |

翻译完成（除烧录模式外）会自动打开**译文调整器**让你确认/修正译文，点 **生成字幕** 输出字幕（格式单选：必剪 `.bcc` / `.ass`）。烧录字幕的颜色/描边/位置在**译文调整器**的「字幕样式」组里设置，存在该视频工作目录的 `.jpsub/style.json`，主页的「烧录」「生成字幕」会用同一份样式（详见 [edit.md](edit.md)）；「下载+烧录」时工作目录还是新建的、没有样式文件，按默认样式（白字、橙描边、底部）烧录，可在「编辑」里改样式后重烧。

下载完成后工作目录里会存有 `info.txt`（标题/作者/简介/标签等元信息，供翻译参考）和封面 `cover.jpg`。**关闭或刷新主页标签页都不影响程序**，后台任务继续运行；只有点右上角「退出程序」才会终止程序（含所有任务与编辑/打码窗口）。关闭**译文调整器**或**打码选取器**页面只结束该窗口，不影响主页程序。

页面底部的灰字有每个按钮的详细说明。个别参数（如 `--fps 2.0`、`--comment 剧场`）可填在 ③ 的「自定义参数」框，会追加到之后发起的所有命令后。
