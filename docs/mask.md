# 打码（马赛克/遮挡敏感画面）

![打码选取器](mask.png)

主页 ② 选中条目点「打码」（或命令行 `jpsub mask output/sm43168834.mp4`），会自动在浏览器打开打码选取器（本地页面，关闭即可）。左侧操作区按用途分成 **时间与定位 / 效果 / 保存与应用 / 还原与备份** 四块，右侧整列是打码列表（「导出片段」按钮在左侧「保存与应用」组里），操作方式：

- **拖动时间轴**或点击画面下方的滑杆选择时刻；键盘更精确：`←/→`（或 `A/D`）±1秒（`Shift` ±0.1秒，`Alt` ±5秒），`W/S` 或 `PageUp/PageDown` ±10秒，`Home/End` 跳到首尾，`Q` 播放/暂停，`C` 新增打码（沿用上次区域），`Z/X` 设当前条目的开始/结束，`V` 新增「裁掉」片段；
- **在画面上直接拖拽框选**要打码的区域，新条目默认从当前帧持续 5 秒（列表里可改，支持 `2:30.5` 或秒数两种写法）；
- **效果**五选一：`模糊`（可调强度）、`纯色`（取色器选色）、`图片`（点「选图片…」上传）、`静音`（只消音不打画面，另有音量倍率可调）、`裁掉`（该时间段整段剔除，应用/导出时删去，不占画面区域）；
- 点 **保存** 写入 `masks.json`（在视频工作目录），点 **应用打码** 直接输出 `sm43168834.masked.mp4`；点 **导出片段** 可把当前生效的时间段打码后单独导出成短片段。

也可以命令行单独应用（比如手动改过 masks.json）：`jpsub maskapply output/sm43168834.mp4`。加 `--burn` 可在打码后接着把同名 `.ass` 字幕烧进结果，一步得到打码+字幕的成品——主页的「烧录」按钮检测到工作目录里有 masks.json 时会自动走这条链路。

masks.json 为 JSON 数组，每条含起止秒、像素坐标与效果，可直接手工编辑：

```json
[
  {
    "start": 58.0,
    "end": 67.5,
    "x": 100,
    "y": 200,
    "w": 300,
    "h": 120,
    "effect": "blur:25"
  },
  {
    "start": 80.0,
    "end": 90.0,
    "x": 0,
    "y": 0,
    "w": 640,
    "h": 360,
    "effect": "color:000000"
  },
  {
    "start": 100.0,
    "end": 110.0,
    "x": 10,
    "y": 10,
    "w": 200,
    "h": 100,
    "effect": "/tmp/jpsub_mask_img/mask_img_1.png"
  }
]
```

> 旧版的 `masks.txt` 文本格式仍能自动识别读取，无需手动转换。
