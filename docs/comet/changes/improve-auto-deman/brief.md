# 目标

提升 `jpsub mask --auto`（自动去人）的肤色检出召回：当前肤色判据范围过窄，深色/阴影/暖色调皮肤被漏检，导致「只能去除一部分」。在不引入模型权重、外部服务或新增第三方依赖的前提下，扩大可检出肤色范围并降低漏检。

已定位的根因（证据）：`jpsub/mask.py` 的 `_skin_mask` 要求 RGB 规则 `r > 95`、`np.abs(r - g) > 15` 与 YCbCr 规则同时成立。对参考片人工基线（`masks.json.bak`，122 条）逐条取帧统计：框内 `rgb_rule` 命中率中位数仅 27.8%，16/122 条低于 5%；低亮度场景（框内亮度中位 58–75）与 R-G 差 12 左右的暗肤色被 `r > 95` / `|r-g| > 15` 直接排除。以该基线为对照，当前自动结果仅 30% 命中。

# 范围

- `jpsub/mask.py` 的肤色判据与区域筛选：`_skin_mask`、`_skin_regions` 及配套常量。
- 评估使用 `output/*/.jpsub/masks.json` 这些人工标注作为对照集。
- 保持输出落盘路径、字段格式与 `jpsub maskapply` 应用链路不变。

# 非目标

- 不引入机器学习模型、外部服务或新增第三方依赖。
- 不改变无参 `jpsub mask` 手工选取器与 `jpsub maskapply` 的行为与输出。
- 不改变 `masks.json` 字段格式与现有 `MaskEntry` / `parse_masks` / `save_masks` 契约。
- 不解决「非肤色真人区域」（如纯黑衣物、黑发、大面积深色轮廓）的漏检，只扩大肤色判据本身。

# 验收示例

对照集：`output/` 下全部含人工标注的片子（8 部），以其人工 `masks.json`（参考片因已被自动结果覆盖，改用 `masks.json.bak`）为「应该去掉」的真值；基线秒共 251 个。

- WHEN 对对照集执行 `jpsub mask --auto`
- THEN 相对人工基线的召回（相交命中）≥ 35%（当前实测 16%）
- AND 覆盖基线框内 ≥50% 面积的命中 ≥ 15%（当前实测 5%）
- AND 任一条自动条目的外接矩形面积 < 整帧 60%
- AND 每部片子的输出仍可被 `parse_masks` 解析、`start < end`、`w > 0`、`h > 0`

参考片（`TAKUYA -タイト- 4話(終)`）关键时刻：

- WHEN 对参考片执行 `jpsub mask --auto`
- THEN 16s、56s、1172s 各至少一条覆盖该时刻的条目，且与同刻手工框（或 `.bak` 框）相交面积 > 0
- AND 1200s、600s 无肤色内容时刻不产生覆盖（或覆盖 < 5%）
- AND 单条最大面积 < 整帧 60%
- AND `maskapply` 后 16s、56s、1172s 基线框内 ≥ 80% 像素纯黑（RGB 各通道 ≤ 8）
- AND 输出视频时长 1261.27s（±0.5s）与 30fps 同原片一致

# 约束与不变量

- 不新增第三方依赖，不访问外部服务。
- `masks.auto.json` 的路径（与手工 `masks.json` 同目录）与字段格式不变。
- 手工 `masks.json` 不被自动流程修改。
- 保留「不整屏 / 不跨半屏误覆盖」的基本约束：单条条目不得覆盖整个画面（外接矩形面积 < 整帧 60%），仍丢弃 > 50% 整帧的合并条目。
- 检测仍按每秒 1 帧抽样，输出仍合并为区间条目。

# 决策

- D1：优化手段限定在肤色判据与像素分布判据的阈值/规则调整范围内（不引入新特征类别、不引入模型）。
- D2：参考片（`TAKUYA -タイト- 4話(終)`）现行 `.jpsub/masks.json` 已被上一轮自动结果覆盖（205 条 == 自动输出），不能作为人工真值；该片真值改用 `.jpsub/masks.json.bak`（122 条）。
- D3：取舍口径为**召回优先**——优先扩大肤色检出，接受一定误报增加；不追求误报最小化。
- D4：验收对照集为 `output/` 下**全部含人工标注的片子**（8 部），非仅参考片。
- D5：主方向为放宽 `_skin_mask` 肤色判据（RGB 规则与 YCbCr 规则由**交集改为并集**，各自阈值下调），并相应放宽 `_skin_regions` 的亮度/填充/面积/梯度筛选；具体数值在 Build 阶段以对照集数据锁定，实测目标为相交召回 ≥ 35%。
