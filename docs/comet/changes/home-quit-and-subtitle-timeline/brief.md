# Outcome

关闭译文编辑器（edit）或打码选取器（mask）页面后，主页（home）不再被连带退出；同时打开多个主页页面时，关闭其中一个不会退出程序，只有最后一个主页页面关闭才退出；并修复 Windows 下因批量拼接帧编号渲染失败导致字幕时间轴崩塌的问题，三项行为在 Windows 与 Linux 一致。

# Scope

- `jpsub/home.py`：
  - 主页启动的 edit/mask（`launch` 型）子进程正常退出时，只更新任务状态与日志，不再触发主页 shutdown。
  - 主页服务登记当前打开的主页页面（加载注册唯一 id、心跳携带 id、pagehide 注销 id）；关闭/刷新/多开据此判定，最后一个页面注销且 2 秒宽限期内无新页面注册才退出。
  - 主页前端 JS 的心跳与 pagehide 通知携带页面 id。
- `jpsub/ocr.py`：
  - `_stitch` 的帧编号字体改为跨平台候选回退（Windows/Linux/macOS 系统字体），全部缺失时使用 Pillow 内置默认字体；不再因平台缺少 Linux 字体路径而跳过编号绘制。
  - `_run_stitched` 无位置版接口切分增加失败防护：批内 n>1 且未匹配到任何区间编号（1..n-1）时视为该接口不可用，不把整批文本并入首帧。
- `docs/home.md`：主页关闭/多开/刷新行为说明同步。

## Source coverage

需求来源为用户在会话中的直接陈述（无外部需求文档）：「编辑/打码网页退出后 home 也会退出，home 应该不退出」；「两个及以上 home 网页打开时，关闭一个不会让程序退出」；「Windows 下生成字幕时间轴有问题并修复」；「1、2 在 Windows 与 Linux 行为一致」。用户指定的两处运行结果目录（`../jpsubwin/output/...`、`output/...`）仅用于排错取证，不作为需求来源，不触发源文档完整覆盖。无逐条来源表。

# Non-goals

- 不改变 edit/mask 页面自身关闭即退出其服务进程的行为。
- 不改变主页「退出程序」按钮（终止全部子进程并退出）的语义。
- 不改变主页其它按钮、请求与任务串行机制。
- 不调整 OCR 接口优先级、额度、缓存格式与设置项，不新增依赖。
- 不新增命令行参数。

# Acceptance examples

- A1：打开主页并启动一个译文编辑器（edit）页，关闭该编辑页使其服务进程退出；主页服务仍可访问（`/ping` 返回 200），主页任务列表不进入退出状态，主页进程不退出。
- A2：同上，关闭打码选取器（mask）页后主页依旧运行。
- A3：同时打开两个主页页面，关闭其中一个（或其中一个刷新），主页服务继续运行，剩下页面的请求正常；只有关闭最后一个主页页面、且 2 秒宽限期内没有新主页页面注册时，主页进程才退出。
- A4：主页页面刷新（pagehide 后立即重新加载）不导致程序退出。
- A5：主页「退出程序」按钮行为不变：终止全部存活子进程并退出程序。
- A6：批量拼接的帧编号渲染不再依赖特定平台的 Linux 字体路径；在系统字体全部不可用的环境下，`_stitch` 仍为 j>0 的帧绘制编号，使无位置版接口可按编号切分。
- A7：无位置版接口切分防护：当一次批量请求返回的行不含任何区间编号且批内帧数 n>1 时，不把全部文本归入首帧，而是切换下一个接口；全部批量接口不可用时退回逐帧识别。
- A8：修复后各帧文本能正确切分回帧，段构建时间轴恢复正常：各段起点严格递增、首段起点为 0，不再出现大量句子挤在数秒区间。

# Constraints and invariants

- Windows 与 Linux 走同一代码路径；不得用平台分支改变用户可见行为。
- 不新增第三方依赖；字体回退只使用 Pillow 与系统字体。
- `/quit` 非空 body 仍是「主动退出程序」；页面关闭判定改为基于页面注册集合。
- edit/mask 子进程被终止（主页退出时）的行为保持原样。

# Decisions

- D1（用户要求）：edit/mask（`launch` 型）子进程正常退出不再联动主页退出，移除该 shutdown 联动，仅更新任务状态与日志。
- D2（用户要求 + 实现选择）：主页页面感知采用「加载即注册唯一 pageId + 心跳携带 pageId + pagehide 注销 pageId」；最后一个页面注销且 2 秒宽限期内无新页面注册才退出；刷新因新页面注册而不误退。
- D3（实现选择）：`_stitch` 字体按候选列表回退（含 Windows/Linux/macOS 常见系统字体路径），全部缺失时使用 Pillow 内置默认字体。
- D4（实现选择）：`_run_stitched` 无位置版切分若未匹配任何区间编号且 n>1，判该接口失败并换下一个接口，全失败则逐帧兜底。

# Verification expectations

- 单元/脚本：将 `_stitch` 的字体候选替换为不存在的路径，断言分隔带为 j>0 的帧绘制了编号像素；构造不含编号行的批量返回，断言切分分支不把整批文本并入首帧。
- HTTP 集成：本机启动主页服务，模拟两个 pageId 的注册/心跳/注销，断言关闭一个后服务仍响应、最后注销后退出；用短命子进程模拟 edit/mask 正常退出，断言主页不退出。
- 时间轴：用修复后的切分结果构造段，断言各段起点严格递增、首段为 0。
- 文档：`docs/home.md` 的关闭/多开/刷新说明与最终行为一致。
