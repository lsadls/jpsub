# 应用生命周期（app-lifecycle）

## Overview

`jpsub` 主页（home）由本地 HTTP 服务承载，浏览器页面与服务进程同生命周期：页面通过心跳（`/ping`）感知服务是否存活，通过 `pagehide` + `navigator.sendBeacon('/quit')` 通知服务「本页面已关闭」。edit（译文编辑器）与 mask（打码选取器）是主页以 `launch` 型子进程启动的独立服务，各自有独立页面与退出逻辑。本能力规定主页服务进程的退出判定：只有在**最后一个主页页面**关闭时才退出，且主页启动的 edit/mask 子进程退出不影响主页。

## Requirement: launch-child-exit-isolated edit/mask 退出不联动主页

主页以 `launch` 型启动的 edit/mask 子进程（其页面关闭即该服务进程退出）正常退出时，主页只更新该任务的终态与日志，不触发主页 shutdown，也不终止其它任务。子进程异常退出同样只记录失败，不退出主页。

### Scenario: 关闭编辑页后主页继续运行

- WHEN 主页启动一个译文编辑器页面，随后该编辑页被关闭、对应子进程以 0 退出
- THEN 主页服务仍可访问（`/ping` 返回 200）
- AND 主页进程不退出，其余任务不被终止

### Scenario: 关闭打码页后主页继续运行

- WHEN 主页启动一个打码选取器页面，随后该打码页被关闭、对应子进程以 0 退出
- THEN 主页服务仍可访问，主页进程不退出

## Requirement: multi-page-aware-quit 多页面感知退出

主页服务的每个页面在加载时注册一个唯一 `pageId`；心跳请求携带该 `pageId` 以保持存活；页面 `pagehide` 时注销该 `pageId`。服务维护当前存活页面集合，只有在**最后一个**已注册页面被注销、且 2 秒宽限期内没有新页面注册时，才关闭主页服务并退出。存在其它已注册页面时，任一页面关闭或刷新都不退出。刷新（`pagehide` 后立即重新加载）因新页面注册而取消退出。

### Scenario: 关闭两个主页页面之一不退出

- WHEN 同时打开两个主页页面，关闭其中一个
- THEN 主页服务继续运行，剩余页面的 `/ping` 与其它请求正常
- AND 主页进程不退出

### Scenario: 关闭最后一个主页页面才退出

- WHEN 仅有一个主页页面打开，关闭该页面且在 2 秒宽限期内没有新页面注册
- THEN 主页服务关闭，程序退出

### Scenario: 刷新主页不退出

- WHEN 主页页面刷新（`pagehide` 后立即重新加载并注册新页面）
- THEN 主页服务继续运行，程序不退出

## Requirement: explicit-quit-unchanged 主动退出语义不变

主页页面「退出程序」按钮走 `/quit` 且请求体非空：终止全部存活子进程（含 edit/mask）后退出程序。该语义不因多页面感知改动而改变。

### Scenario: 退出程序按钮终止全部子进程并退出

- WHEN 在主页点击「退出程序」并确认
- THEN 所有存活子进程被终止
- AND 主页服务关闭、程序退出
