# 三页按钮分组（ui-button-groups）

## Overview

`jpsub` 的三个浏览器页面——主页（`jpsub/home.py`）、译文调整器（`jpsub/edit.py`）、打码选取器（`jpsub/mask.py`）——按钮目前多为平铺排列：主页「对选中项」是十几个按钮一行，edit 与 mask 只有少量无标题的按钮框。本能力把三页按钮按用途分块并加小节标题，主页的删除类按钮独立成危险操作块。分组只改容器结构与文案，不改任何按钮的行为。

## Requirement: 主页按钮分组

主页「① 操作」区按用途分块并显示小节标题：网络下载组、本地视频组、对选中项组（组内再按编辑、产出、翻译、投稿与分享、危险操作分块）。「删除工作目录」「删除视频」必须位于单独的危险操作块，不与常用操作同组；「退出程序」仍独立在页头。

### Scenario: 主页分组与危险操作隔离

- WHEN 打开主页
- THEN 「对选中项」区域按钮分成至少 3 个带可见标题的块
- AND 「删除工作目录」「删除视频」位于单独的危险操作块，该块不含非删除类按钮

## Requirement: edit 页按钮分组

edit 页按钮按用途分块并显示小节标题：时间轴与文本编辑、翻译、保存与输出、字幕样式、字幕文件与烧录、还原与备份；「字幕样式」自成一块，不与其它操作混排。

### Scenario: edit 页分组

- WHEN 打开 edit 页
- THEN 按钮分成至少 4 个带可见标题的块
- AND 「字幕样式」块包含样式控件与本块操作，且不包含翻译、生成字幕以外的按钮

## Requirement: mask 页按钮分组

mask 页按钮按用途分块并显示小节标题：时间与定位、效果（效果选择与参数）、保存与应用、导出、还原与备份。

### Scenario: mask 页分组

- WHEN 打开 mask 页
- THEN 按钮分成至少 3 个带可见标题的块

## Requirement: 分组不改变行为

分组只改容器结构与文案。三页每个按钮的 `id` 与点击行为、键盘快捷键保持不变；页面加载与操作过程中不出现 JS 报错；页面内说明文字与所在分组一致。

### Scenario: 按钮集合与行为不变

- WHEN 对比改动前后三页 HTML 中按钮的 `id` 集合
- THEN 两边集合一致，没有按钮丢失或 id 改名
- AND 逐一触发按钮时请求的目标接口/命令与改动前相同
- AND 页面加载与操作过程中控制台无 JS 报错

## Requirement: 文档同步

`docs/home.md`、`docs/edit.md`、`docs/mask.md` 中的按钮说明与页面实际分组、样式选项与样式保存位置一致。

### Scenario: 文档与页面一致

- WHEN 打开 `docs/home.md`、`docs/edit.md`、`docs/mask.md` 并与对应页面比对
- THEN 文档描述的按钮分组与页面实际分块一致
- AND `docs/edit.md` 说明字幕样式选项与 `.jpsub/style.json` 的保存位置

## 不变量

- 三页仍是自包含内联 HTML/JS，沿用现有深色主题样式，不引入外部资源、构建步骤或新依赖。
- 各按钮对应的 HTTP 接口、子进程命令与参数不变；翻译、打码、烧录、投稿等功能行为不变。
- 危险操作的确认提示（`confirm` / `alert`）保持不变，不因分组而被省略。
